EntraCompass

Find out which business applications sit outside protection, which exceptions are justified, what would break if you tighten, and how well company data is protected on unmanaged devices. Then hand management a clear report.

  • Business apps first. SAML, App Proxy and SaaS apps mapped against every policy.
  • Exception inventory. Every exclusion classified: gap, review, cleanup, stale or justified.
  • DLP lens. Session controls, managed devices, authentication contexts, guests.
  • Named locations and workload identities checked for hidden bypasses.
  • What-if. Test a sign-in scenario before you change a policy.
  • Executive report that answers management questions in plain language.

Runs entirely in your browser. Read-only Microsoft Graph access through your own app registration (PKCE, no secrets). Nothing is stored on a server. Data lives in this browser tab and is cleared when you close it.

  2. Platform: Single-page application (not Web). Redirect URI:
  3. API permissions > Microsoft Graph > Delegated: Policy.Read.All, Application.Read.All, Directory.Read.All, AuditLog.Read.All, User.Read. Then Grant admin consent.
  4. Copy the Application (client) ID and Directory (tenant) ID below.
