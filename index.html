EntraCompass

Find out which business applications and AI agents sit outside protection, which exceptions are justified, what would break if you tighten, and whether your Purview DLP really reaches the data. Then hand management a clear report.

  • Business apps first. SAML, App Proxy and SaaS apps mapped against every policy.
  • Exception inventory. Every exclusion classified: gap, review, cleanup, stale or justified.
  • AI agents. Entra Agent ID inventory, Conditional Access for agents, agent risk, sponsors and permissions. Preview
  • Purview and DLP. Sensitivity labels, DLP locations including Copilot, cross-checked with Conditional Access.
  • Workload identities and named locations checked for hidden bypasses and over-privileged apps.
  • What-if for people, guests and agents, and an executive report in plain language.

Runs entirely in your browser. Read-only Microsoft Graph access through your own app registration (PKCE, no secrets). Nothing is stored on a server. Data lives in this browser tab and is cleared when you close it.

Connect your tenant

Uses an app registration in your own tenant. How to create it

  1. Entra admin center > App registrations > New registration. Single tenant.
  2. Platform: Single-page application (not Web). Redirect URI:
  3. API permissions > Microsoft Graph > Delegated: Policy.Read.All, Application.Read.All, Directory.Read.All, AuditLog.Read.All, User.Read. Then Grant admin consent.
  4. Optional, for the agent and Purview views: AgentIdentity.Read.All, IdentityRiskyAgent.Read.All, InformationProtectionPolicy.Read. Without them those checks run with less detail.
  5. Copy the Application (client) ID and Directory (tenant) ID below.

Or run infra/New-EntraCompassApp.ps1 from the GitHub repo to create it for you.
